## SISTEMA DE ESTACIONAMIENTO

###### Menú principal

Se mostrara las opciones que realiza el programa. Se puede seleccionar según el número asignado a la opción.

En la opción 1 es la opción donde se ingresa cuantos vehiculos quiera el usuario al sistema, para la opción 2 se retira el/los vehiculo(s) del sistema, opción 3 se muestra el tablero del estacionamiento, cuantos hay ocupados y vacios, la salida, entrada y la vía exterior, opción 4 se busca el vehiculo por número de placa, opción 5 se muestra la ruta más corta para que el vehículo estacione, opción 6 muestra los ingresos recaudados hasta ese momento y la opción 7 finaliza la ejecución del programa.

clase:    

 public class menu{

Atributos:

-  int ingrecarr

-  int salircarr 

- int mostestacion (Mostrar estacionamiento)

- int placa 

- int  ruta 

- int ingresos

- int salir
  
          

Métodos: 

sistema de condición

Para ingrecarr:
Se selecciona el número 1 para ingresar 

Para salircarr:
Se selecciona el número 2 para ingresar

Para mostestacion:
Se selecciona el número 3 para ingresar

Para placa:
Se selecciona el número 4 para ingresar

Para ruta: 
Se selecciona el número 5 para ingresar

Para ingresos:
Se selecciona el número 6 para ingresar

Para salir:
Se selecciona el número 7 para ingresar
